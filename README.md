# 📝 Gerenciador de Tarefas em Python

Aplicação de linha de comando desenvolvida em Python para gerenciamento
de tarefas do dia a dia.

## 🚀 Funcionalidades

- Adicionar tarefas
- Visualizar tarefas
- Atualizar tarefas
- Marcar tarefas como concluídas
- Remover tarefas concluídas
- Validação das entradas do usuário

## 🛠️ Tecnologias

- Python 3
- Estruturas de dados
- Funções
- Loops
- Condicionais
- Tratamento de exceções
